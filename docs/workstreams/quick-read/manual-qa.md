# Windows 11 — Quick Read manual QA

Матрица ниже задаёт ожидаемое поведение; фактические результаты и границы — под
таблицей. Компиляция и unit-тесты не подтверждают GUI, звук, качество OCR,
поддержку конкретного приложения или задержку.
Тестировать на изолированной тестовой библиотеке, без приватного текста в evidence.

Замеры на cold/warm worker: горячая клавиша → извлечение → первый PCM → первый
слышимый звук. Последняя граница измеряется manual, факт заполнения очереди не
заменяет измерение звука. Проверить задержки на длинном предложении и на коротком
выделении. Изменение скорости в первой версии меняет темп и высоту голоса.

именно этого варианта ещё NOT_RUN. Начальная попытка без foreground и ошибка
localhost у ошибочно запущенного Cargo EXE сохранены как FAIL в журнале; после
сборки Tauri CLI пользователь подтвердил отсутствие localhost ошибки.
